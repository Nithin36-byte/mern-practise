\# Task 2 - JavaScript Fundamentals



\## Objective

To practise JavaScript concepts required for React and Node.js development.



\## Topics Covered



1\. Variables using let and const.

2\. Strings, numbers, booleans, arrays, objects and null.

3\. Conditional statements and loops.

4\. Regular functions and arrow functions.

5\. Array methods: map(), filter(), find(), some() and reduce().

6\. Array and object destructuring.

7\. Spread and rest syntax.

8\. JavaScript modules using import and export.

9\. Promises and async/await.

10\. Error handling using try/catch.

11\. Fetch API requests.

12\. JSON serialization and parsing.

13\. Optional chaining and nullish coalescing.



\## Practice Files



\- student.js - Student data and reusable function.

\- app.js - Importing and using JavaScript modules.

\- async-practice.js - Promise and async/await practice.

\- error-practice.js - Error handling.

\- fetch-practice.js - Retrieving data from an API.

\- json-practice.js - JSON and modern JavaScript syntax.

\- student-exercises.js - Student management exercises.



\## How to Run



Open the terminal inside the task2-modules folder.



Run individual files using Node.js:



```bash

node app.js

node async-practice.js

node error-practice.js

node fetch-practice.js

node json-practice.js

node student-exercises.js

```



\## Expected Result



A collection of JavaScript exercises demonstrating fundamental programming concepts, array and object operations, API requests and asynchronous programming.
